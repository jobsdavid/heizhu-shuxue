# 黑猪数学 TV

小米电视 / Android TV 上的小学数学口算闯关应用。遥控器操作，数据全部存在本机 SQLite。

- 加减乘除按小学课标拆成 **12 个台阶**，每阶只改一个变量（数域 / 进退位 / 通分）
- **答对才走**；同一个坑连错 3 次自动跳过，语音提示该补哪块，题目记进错题本
- 算力 0~1000 + 六档段位，成长曲线 / 练习热力图 / 12 个成就
- 挑战电脑：2 场满分考试换 1 次挑战；电脑速度 = 最快 5 场考试的平均每题用时 ×0.8

## 一、能做什么

| 功能 | 说明 |
|------|------|
| 难度 | S1~S12 共 12 个台阶，从 10 以内加减到分数通分；加减同台、乘除各自独立 |
| 练习 | 首页主入口，答对才走；设置里可切换成限时（每题倒计时） |
| 考试 | 首页主入口，20 题统一判卷，用来测真实水平 |
| 题型 | 计算、找错（给个算错的式子让娃改）、填空（求括号里的数）、混着来 |
| 分数 | 真·上下结构排版（不是 1/2 斜杠）；只填分子，分母由题面给；分数不朗读 |
| 挑战电脑 | 同题竞速，电脑速度 = 最快 5 场考试的平均每题用时 ×0.8；2 场满分考试换 1 次，可累积 |
| 每日挑战 | 每天固定一组 10 题（同一天同一套），全对点亮当天，连续打卡 |
| 错题本 | 第一次答错就收录；同一题连错 3 次自动跳过（已记错题本），连对 2 次毕业 |
| 成长曲线 | 正确率 / 速度 / 知识点正确率 / 练习热力图 |
| 算力与段位 | 0~1000 分，数学小学徒 → 数学大王 |
| 成就墙 | 12 个成就，实时判定 |
| 语音 | 内置语音包朗读题目，练习/限时/考试语速不同，带符号停顿 |
| 我的资料 | 12 个表情头像 + 24 个预设昵称；也可以用**手机扫码传自己的照片、打中文名** |

## 三、阶段与题型

阶段按小学课标排成 12 个台阶，**加减是一体的（同阶段混着出），乘法和除法各自独立**：

| id | 阶段 | 考什么 | 特殊规则 |
|----|------|--------|----------|
| s1 | 10 以内加减 | 数感入门 | 只出不进位/不退位 |
| s2 | 20 以内加减 | 进位加、退位减 | 必须有进位或退位 |
| s3 | 50 以内加减 | 两位数 | 随意 |
| s4 | 100 以内加减 | 两位数综合 | 随意 |
| s5 | 表内乘法 | 九九表 | 2~9 |
| s6 | 表内除法 | 用口诀倒推 | 整除 |
| s7 | 乘除混合 | 看清符号 | 2~9 |
| s8 | 两位数乘一位数 | 拆十位再乘 | 10~99 × 2~9 |
| s9 | 三位数除以一位数 | 从高位除起 | 100~999 ÷ 2~9，整除 |
| s10 | 100 以内四则混合 | 四个符号全上 | 加减按 100 以内 |
| s11 | 分数初步 | 同分母加减 | 分母 3~10，真分数 |
| s12 | 分数进阶 | 通分 | 一个分母是另一个的倍数，答案分母固定 |

**阶段在哪看**：设置 → 学习阶段（按 OK 进「阶段地图」）。地图一屏列出 s1~s12，
每阶写着练什么、自己的成绩、还差多少解锁；点任意一阶弹出详情（完整介绍 + 成绩 + 解锁条件），
已解锁的可以直接「就练这个」切过去。

**解锁规则**：在当前阶段的**累计**成绩（不是某一局的手气）同时满足四条才解锁下一阶段：

1. ≥20 题
2. 正确率 ≥ **95%**
3. 平均每题用时 ≤ **阶段目标秒数**（s1 5s、s3 7s、s4 8s、s9 11s…）——「基本不用思考」的速度
4. 算力 ≥ **该阶段理论上限的 80%**（`Settings.POWER_TARGET_RATIO`）—— 卡「练够量没有」

四条哪里没达标，首页练习卡、结果页、阶段地图都会写出来（「还差 12 题 / 正确率到 95% /
再快 0.6 秒/题 / 算力还差 26」）。阶段地图点进任意一阶，能看到该阶的完整战绩与解锁条件明细。
家长也可以在设置里一键「解锁全部阶段」。

**挑战规则**：该阶段每 **2 场满分考试**换 **1 次**挑战，可累积不清零，每开一局花 1 次。
电脑速度 = 该阶段「最快的 5 场考试」的平均每题用时 × 0.8（优先取正确率 ≥80% 的场次）——
只跟着考试走，挑战成绩不回喂基准，所以不会被自己刷到不可战胜。

**多孩子**：一台电视可以建多个孩子，点右上角头像 → 顶部「＋ 新孩子」新建，点头像切人。
数据完全隔离：每人一个 `mathking_u<id>.db` + 一份 `mathking_u<id>` 偏好，不会串。
老版本的单人数据会在升级后自动搬进 1 号孩子（库文件复制一份，原文件保留）。

**换难度**：首页「难度 `S1 · 10 以内加减` ›」那一行进难度一览，选哪档练哪档；设置里的难度行按左右键也能快速切。
卡片上的左右键只负责走焦点（别再占用来换难度，孩子会以为坏了）。

**分数怎么答**：题面给出公分母，孩子只填分子。
`1/2 + 2/6 =` 后面是 `?/6`，填 5 就是 5/6。这样数字键盘就够了，不用输入分数线。

**分数怎么显示**：存储一律是 `3/4` 纯文本，展示时用 `FractionSpan`（ReplacementSpan）
画成上下结构；答案框用固定布局画（`answerFraction`），避免 TextView 行高裁掉分数的上下两行。
分数题不朗读——语音包是按整数念的，念分数反而听不明白。

## 四、语音包

电视上没有中文 TTS 引擎（实测小米电视 `tts_default_synth = null`），所以题目朗读用内置音频拼接。

词表在 **`app/src/main/assets/voice/lexicon.json`**，一份数据两头用：

```json
{ "token": "等于", "file": "dengyu", "text": "等于" }
```

- `token`：App 里写的朗读片段（`Generator`/`Speech` 拼句子用这个）
- `file`：`assets/voice/raw/<file>.raw`，22050Hz 单声道 16bit 裸 PCM
- `text`：交给 edge-tts 的原文（带标点，让断句自然）

**加新词只改 json，然后重生成音频**（venv 在项目内，不污染系统）：

```bash
cd ~/kids-tv
.venv/bin/python tools/gen_voice.py          # 只补缺的
.venv/bin/python tools/gen_voice.py --force  # 全部重生成
.venv/bin/python tools/gen_voice.py --check  # 体检：词表每条都有音频吗
```

**踩过的坑（别踩回去）**

1. 朗读是「按词拼音频」，词表里没有的字会被**静默丢掉**。历史上「等于」「括号」就是这么没的，
   导致找错题不读等号、填空题只念「加 五 等于 十二」。
   现在 `SpeechLexicon.uncovered()` 会报出漏读的字，`SpeechCoverageTest` 直接断言它为空，
   覆盖所有阶段 × 题型 × 结算播报。改朗读文案后一定先跑 `gradle testDebugUnitTest`。
2. 判断语音包在不在，**别用** `assets.list("voice/raw").size`：部分构建产出的 APK 没有目录条目，
   会返回空数组，于是整包语音被判「不存在」、静默退回系统 TTS（电视上等于没声音）。
   现在直接尝试打开词表里第一个文件。
3. 数字要先转中文：`Speech.expression("2 + 5")` 必须给「二 加 五」，直接塞阿拉伯数字会被吞掉。

## 七、手机扫码填资料

电视遥控器打中文太痛苦，所以资料页里有个「手机扫码改名字和头像」：

1. 电视打开「我的资料 → 手机扫码」，起一个临时 HTTP 服务（随机端口）并显示二维码
2. 手机连同一个 WiFi，扫码打开网页：可以打中文名字、选表情头像，也可以**选一张手机里的照片**
   （浏览器端用 canvas 裁成正方形压到 256×256 JPEG 再上传，避免大图走局域网）
3. 提交后电视自动关掉资料页，回首页直接看到新名字和新头像

实现：`net/LocalWebServer.kt`，手写 GET/POST 解析，没有引 HTTP 框架；
二维码用 `com.google.zxing:core`（只引 core，不引 android 版）。
服务只在对话框打开期间运行，关掉即停，不对局域网常驻暴露。

## 八、数据

`~/kids-tv` 内的 SQLite 文件在电视上：`/data/data/com.mathking.tv/databases/mathking.db`

| 表 | 用途 |
|----|------|
| session | 每一局（阶段、模式、题数、正确数、用时、得分、算力） |
| attempt | 每一题（题面、答案、作答、是否首次答对、用时、知识点） |
| wrong_item | 错题本（错误次数、连续答对、是否毕业、知识点） |
| daily | 每日挑战（日期、题数、正确数） |
| sync_queue | 预留：网络对战成绩上报 |

数据库版本 3，升级走 `onUpgrade` 逐级 ALTER/CREATE，不会清数据。

## 九、口径约定（改代码前先看这条）

- **算力 / 今日 / 成长曲线 / 知识点统计** 全部排除 `mode='challenge'`（抢答正确率天然低，混进来会失真）
- 阶段解锁看**该阶段累计**：≥20 题且正确率 ≥85%（`Settings.UNLOCK_MIN_*`）
- 错题重练保留原始知识点，不记成「错题重练」
- 首次答对才算「做对」；重答正确只让错题本计一次 streak

## 九点五、答题页的交互约定（改之前先读）

一局答题只有三个状态：`ANSWERING`（能输入）→ `LOCKED`（刚提交，正在播反馈）→ `ADVANCING`（翻页中）。

| 场景 | 现在的行为 | 为什么 |
|------|------------|--------|
| 提交答案 | **不清空输入框**，数字留着，答对绿框 / 答错红框 | 清了会在播「回答正确」时把答案变回「?」，孩子以为答案被吞了 |
| 换题 | 题面+答案框从右侧滑入淡入（230ms） | 直接「啪」一下换掉会看不出发生了翻页 |
| 练习答错 | 停在本题，语音「回答错误 + 该补的思路 + 再算一遍」，输入框留着错答案，一按数字就重新开始 | 一年级孩子不会自己找错因 |
| 考试 | 每题必须按 ✓，答完**不告诉对错**，也不写「已记录」这类程序状态 | 原来填满正确答案 160ms 就自动翻页，等于泄题 |
| 连错 3 次 | 跳过这题，把知识点留到下一题的提示行 | 不让孩子卡死在一道题上 |
| 发呆 10 秒 | 重读题面 + 给思路提示，**最多 2 次** | 推一把，但不唠叨 |
| 一局结束 | 结果页自动播报：题数、正确数、星数、一句针对性建议 | 孩子不看小字 |
| 错题本 | 聚焦某题停 **0.8 秒**自动讲解（题面→答案→思路）；换题立刻掐断上一条语音；按 ✓ 暂停/继续 | 想停下来自己想 |
| 语音播报 | 反馈语音**播完才换题**（`Speaker.speak(text, rate, then)`） | 否则「回答正确」永远读半句就被下一题打断 |

连错 3 次那题记的是 3 次尝试、首次未答对，所以一定会出现在错题本里。
